01 Routing

The ten-second router

One table. Find the row that matches what you have in hand; reach for what sits beside it. No decision tree, no ceremony.

You have Reach for
A trivial edit, or a pure question just ask — no machinery
A plan to execute in stages /orchestrate
A meaningful change from a raw request /build-system Sizes its docs to the work: PRD + Plan for large, one Spec for medium, none for small.
GitHub issues to resolve, or a PR to ship /ship-issues
A PR that needs review only /pr-auto-review
A non-code deliverable — research, proposal, docs /teamwork
A long, unattended goal /auto-run
A batch of decisions for the human /make-it-easy  or  /askme
A plan to stress-test with the human /grill-me

First match wins, top to bottom.

02 Review

Review tiers

Three ascending tiers, cheapest to widest. Wrap any of them in a fix loop when one pass isn’t enough.

Claude reviewer Codex reviewer Findings deduped & validated against the actual diff.

Convergence is the goal.
The cap is the cost guard.

The loop runs review → fix → re-review until it converges, hits steady state, regresses, or reaches the round cap.

Two reviewers from different vendors disagree in useful ways — dedup what they agree on, investigate what they don’t. /quick-review is one inline Claude pass. /dual-review adds a detached Codex CLI reviewer on the same scope. /lens-review fans out a Claude + Codex pair per lens — the widest net, read-only.
